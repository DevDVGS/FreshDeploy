# Browser preview

Run `npm run preview:report`, then serve the repository root with `py -m http.server 8000` (or `python -m http.server 8000`) and open `http://localhost:8000/preview/`.

The public report is generated by a real local inspection. It shows WARN for the sample server's absent Cache-Control header. Change the sample and run `npm run preview:report` again to regenerate the manifest and the result. This page is an example, not your production site's report.
